# Google Flow / Veo 3 제작 가이드

Flow의 메뉴 이름과 지원 옵션은 업데이트로 자주 바뀐다. 아래는 원칙 중심으로 정리했다.
화면이 다르면 같은 기능(시작 프레임 지정, 레퍼런스 이미지, 이어서 생성)을 찾아 쓰면 된다.

## 1. 모드 선택

| Flow 모드 | 언제 쓰나 | 이 스킬에서의 용도 |
|---|---|---|
| **Frames to Video** (시작 프레임 / 시작+끝 프레임) | 첫 화면을 정확히 고정할 때 | 클립 1: 키프레임을 시작 프레임으로. 클립 2~4: 앞 클립 마지막 프레임을 시작 프레임으로 |
| **Ingredients to Video** (레퍼런스 이미지 여러 장) | 인물·소품을 여러 장면에서 같게 유지할 때 | 시작 프레임 없이 새 구도로 넘어갈 때(예: 서류 클로즈업 후 다시 인물) 인물 시트를 넣는다 |
| **Extend** (Scene builder에서 이어서 생성) | 직전 클립을 끊김 없이 이어 갈 때 | 같은 장소·같은 카메라 축이면 가장 편하다. 프롬프트에는 "이어지는 8초" 내용만 쓴다 |
| **Text to Video** | 참고 이미지가 없을 때 | 이 스킬에서는 가급적 쓰지 않는다 (얼굴이 매번 바뀜) |

권장 조합:
- 클립 1 → Frames to Video (키프레임)
- 클립 2 → Extend 또는 클립 1 마지막 프레임으로 Frames to Video
- 클립 3 → 반전 컷. 인물 시트로 Ingredients, 또는 Extend
- 클립 4 → Extend 또는 클립 3 마지막 프레임으로 Frames to Video

## 2. 기본 설정 체크

- 모델: Veo 3 계열 중 **소리(대사) 생성이 되는 모델**을 고른다. Fast 모델은 시안용, 최종본은 Quality 모델.
- 비율: **9:16 세로**. 세로가 안 보이면 16:9로 만들고 편집에서 크롭하되, 프롬프트에 `subject centered, safe for vertical crop`를 넣는다.
- 생성 개수: 크레딧을 아끼려면 1개, 고를 여유가 필요하면 2개.
- 길이: 클립당 8초 (Veo 3 기본).

## 3. 인물 일관성

1. 키프레임과 인물 시트를 **같은 인물 묘사 문장**으로 만든다.
2. 모든 클립 프롬프트에 그 문장(캐릭터 앵커)을 글자 그대로 넣는다.
   예: `a Korean man in his early 70s, thin grey hair, deep wrinkles, wire-rimmed glasses, navy security guard uniform with a cap and a name badge`
3. 의상 색·안경·모자 같은 **눈에 띄는 고정 요소 2~3개**를 정해 두면 흔들림이 줄어든다.
4. 클립을 이을 때는 앞 클립 마지막 프레임을 저장해 다음 클립 시작 프레임으로 쓴다.
   (Flow에서 프레임 저장이 안 되면 영상을 받아 마지막 프레임을 캡처한다.)

## 4. 한국어 대사 팁

- 대사는 반드시 큰따옴표 안 **한국어 원문**. 앞에 `says in Korean`을 붙인다.
- 화자를 생김새로 지정한다: `The elderly guard in the navy uniform says in Korean, in a calm low voice: "..."`
- 한 클립에 화자 2명까지. 3명 이상이면 입 모양이 섞인다.
- **클립당 35음절 이내**. 길면 말이 빨라지거나 잘린다.
- 말투도 지시한다: `shouting angrily`, `sneering`, `calm and quiet`, `voice trembling`.
- 외래어·숫자는 한글로 풀어 쓴다 (`3개월` → `석 달`).
- 발음이 뭉개지면: 대사를 더 짧게 → 문장을 끊어 두 번에 나눠 말하게 → 그래도 안 되면 편집에서 TTS·더빙으로 교체.

## 5. 소리 지시

매 클립 끝에 넣는다.

```
Audio: No background music. Only Korean dialogue and natural ambient sound: <현장음>.
```

현장음 예시: 아파트 주차장 바람 소리, 플라스틱 컵이 바닥에 튀는 소리, 종이 넘기는 소리, 경비실 문 닫히는 소리, 멀리 차 지나가는 소리.

## 6. 화면 속 글자

- Veo는 자막을 임의로 넣는 경우가 있다 → 매 클립 `No subtitles, no captions, no on-screen text, no watermark.`
- 서류·명패의 한글은 대부분 뭉개진다. 해결책:
  1. 서류 클로즈업은 나노바나나로 **정지 이미지 인서트**를 만들어 편집에서 1~1.5초 넣는다.
  2. 또는 서류는 글자 없이(`text not legible`) 찍고, 편집에서 이름·문구를 자막/그래픽으로 얹는다.
- 반전 핵심 글자는 **화면에 1초 이상** 정확히 보여야 한다 (원본 제작 메모 유지).

## 7. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 클립마다 얼굴이 달라짐 | 시작 프레임 사용, 캐릭터 앵커 문장 반복, Ingredients에 인물 시트 추가 |
| 대사를 다른 사람이 말함 | 화자를 옷·나이·위치로 지정, 한 클립 화자 2명 이하 |
| 대사가 잘림·빨라짐 | 음절 줄이기, 동작 지시 줄이기 |
| 배경음악이 깔림 | `No background music` 문장을 앞쪽과 끝에 두 번 |
| 자막이 생김 | `no subtitles` 문장 유지, 그래도 생기면 다시 생성 |
| 클립 경계가 튐 | 앞 클립 마지막 프레임을 시작 프레임으로, 또는 Extend 사용 |
| 가로로 나옴 | 비율 설정 재확인, 안 되면 16:9 + 중앙 구도 후 크롭 |

## 8. 편집 마무리 (CapCut, Vrew, 프리미어 등)

1. 클립 1~4를 순서대로 놓고 32초 → 30초로 다듬는다 (각 클립 앞뒤 여유분 0.3~0.5초 자르기).
2. 반전 인서트 이미지(서류 등)를 클립 3 해당 지점에 1~1.5초 삽입.
3. 자막: 원본 대본의 자막·엔딩 카드 문구는 **편집에서** 넣는다 (영상 생성에는 넣지 않음).
4. 음향 리듬: 시작은 컵 떨어지는 소리, 반전은 종이 넘기는 소리 — 필요하면 효과음 보강.
5. 대사 발음이 나쁜 구간은 자막으로 보완하거나 해당 클립만 다시 생성.
