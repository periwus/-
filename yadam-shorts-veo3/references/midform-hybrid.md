# 3분 미드폼 모드 (Veo 인트로 + 브루·캡컷 본편)

## 왜 이 형식인가

| 길이 | 역할 |
|---|---|
| 30초 쇼츠 | 처음 보는 사람을 붙잡는다 (노출) |
| **2분 30초~2분 59초 미드폼** | **이야기를 끝까지 들려주고 "이 채널 이야기는 재밌다"는 믿음을 준다 (구독)** |
| 롱폼 (약 120분) | 구독자가 오래 머문다 (시청 시간, 수익) |

- 유튜브 쇼츠는 3분까지 올릴 수 있으므로 3분 미만이면 쇼츠 피드에 노출된다.
- 3분 전체를 Veo로 만들면 8초 클립이 약 23개 필요하다. 그래서 **인트로만 Veo 영상, 본편은 이미지 + 움직임 효과**로 제작비를 줄인다.

## 시간 구조

| 구간 | 방식 | 내용 |
|---|---|---|
| 0~16초 | Veo 3 클립 2개 | **콜드 오픈:** 이야기에서 가장 강한 장면 (보통 절정 직전). 마지막 대사로 궁금증을 남긴다 |
| 16~18초 | 편집 | 흰 화면 번쩍임 + 제목 자막 |
| 18초~2분 50초 | 브루 나레이션 + 이미지 | 처음부터 다시: 배경 → 꼬임 → 인트로 장면으로 돌아옴 → 진상 → 판결·반전 |
| 마지막 5~10초 | 이미지 + 나레이션 | 여운 + **다음 편 예고** ("그리고 3년 뒤…") |

재후킹: 30~40초마다 "그런데…", "🔔"로 표시한 문장을 하나씩 넣는다. 보통 4~5개.

## 나레이션 분량

- 한국어 TTS는 분당 약 300~330음절이다.
- 본편 2분 20~30초 = **약 750~800음절**. 대본을 쓴 뒤 한글 음절 수를 세어 사용자에게 알린다.
- ⏸(0.5초 쉼)은 장면당 하나 이하로 넣는다.

## 브루 장면표 형식

| 장면 | 이미지 내용 | 나레이션 | 효과 |
|---|---|---|---|
| s03 | <한 장면 한 문장. 인물·장소·감정> | <1~2문장, 6~10초 분량> | <캡컷 효과> |

- 파일명은 `s03.png`부터 시작한다 (s01·s02는 Veo 클립 자리).
- 장면 하나는 6~10초다. 3분이면 장면 20~24개가 된다.
- 대사는 나레이션 안에 큰따옴표로 넣는다. 브루 자막에서 크게 강조한다.

## 캡컷 효과 고르는 법

| 장면 성격 | 효과 |
|---|---|
| 배경·전경 소개 | 천천히 줌아웃, 안개 오버레이 |
| 인물 등장·이동 | 좌→우 팬, 아래→위 팬 |
| 감정·의심·깨달음 | 얼굴로 느린 줌인, 비네팅 |
| 단서 발견 | 단서로 강한 줌인 + 플래시 전환 |
| 충격·포효·판결 | 흔들림 0.3~0.5초 + 빠른 줌인 |
| 밤·위험 | 화면 어둡게, 횃불 불꽃 오버레이 |
| 여운·엔딩 | 아주 느린 줌아웃, 페이드아웃 |

브루만 쓸 때는 이미지 애니메이션의 확대·축소·이동으로 대신한다. 같은 효과가 3장면 넘게 이어지지 않게 섞는다.

## 장면 이미지 프롬프트 규칙

1. **인물 레퍼런스(R1, R2…)를 먼저** 만들고, 장면마다 "첨부: R1, R2"를 표시한다.
2. 모든 장면 앞에 공통 스타일 문구를 붙인다. 9:16, 실사 사극, 차분한 색, 필름 그레인, **줌·팬을 위한 여백**, 글자 없음.
3. 인물 묘사는 인트로 Veo 프롬프트의 캐릭터 앵커와 같은 문장을 쓴다.
4. 이야기 단서(옷고름의 진흙, 표식 등)는 프롬프트에 분명히 적고, 결과 확인 체크리스트에 넣는다.
5. 조선 배경이면 복식 고증 메모 표를 붙인다. 수령은 네모 흉배와 사모, 아전은 도포와 갓, 포졸은 전립과 더그레를 쓴다. `yadam-flow-prompts` 스킬이 있으면 그 기준을 우선한다.

## 구독으로 연결하는 장치 (편집 메모에 넣기)

- **시리즈 이름과 회차:** "원님 시리즈 1화". 같은 주인공이 계속 나온다는 기대를 만든다.
- **첫 문장 고정:** 매 편 같은 도입 문구로 채널을 기억하게 한다.
- **결말은 완결하고 다음 편을 예고:** 결말을 감추고 롱폼으로 미루면 반감을 산다.
- **관련 동영상 링크:** 30초 예고편 → 3분 미드폼 → 롱폼 순서로 연결한다.
- **고정 댓글:** "여러분이 ○○였다면?" 같은 선택형 질문을 남긴다.
- **배경음악:** 1분이 넘는 쇼츠에 Content ID에 걸리는 음원이 있으면 차단될 수 있다. 직접 만든 음원이나 무료 음원만 쓴다.
- **30초 예고편 재활용:** Veo 인트로 16초 + 핵심 장면 이미지 3장 + 압축 나레이션.
- **확인할 지표:** 유튜브 스튜디오에서 영상별 구독자 증감, 쇼츠 본 비율(넘기지 않은 비율), 시청 지속 그래프에서 이탈 지점.
