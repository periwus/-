# 반전 드라마 쇼츠 (Google Flow / Veo 3용)

30초 세로 드라마 쇼츠를 3단계로 만든다. 이 스킬은 **도구를 직접 호출하지 않는다.**
결과물은 사용자가 Google Flow(Veo 3/3.1, 나노바나나) 또는 Gemini 앱에 그대로 복사해 넣을
**대본 + 이미지 프롬프트 + 클립별 영상 프롬프트**다. MCP, 아트리스트, 씨댄스는 쓰지 않는다.

## 먼저 알아야 할 Veo 3의 제약 (씨댄스 원본 워크플로와 다른 점)

| 항목 | 원본(씨댄스 2.5) | 이 스킬(Veo 3 / Flow) |
|---|---|---|
| 길이 | 30초 한 번에 생성 | **클립당 8초** → 8초 × 4클립 = 32초, 편집에서 30초로 자름 |
| 이어붙이기 | 불필요 | 앞 클립의 마지막 프레임을 다음 클립 시작 프레임으로 (Flow `Extend` 또는 프레임 저장) |
| 인물 고정 | 시작 프레임 1장 | 시작 프레임 + **인물 레퍼런스 이미지**(Ingredients) 병행 |
| 대사 | 30초에 대사 전부 | **클립당 대사 1~2줄, 한국어 약 35음절 이내** |
| 화면 속 글자 | 소품으로 처리 | Veo는 한글을 자주 뭉갬 → **서류 인서트는 나노바나나 정지 이미지 또는 편집 자막으로 보완** |

Flow 메뉴 이름·지원 비율·모델 버전은 자주 바뀐다. 사용자가 다르게 보인다고 하면
`references/flow-veo3-guide.md`의 원칙(8초 단위, 시작 프레임, 레퍼런스 고정)을 유지한 채 메뉴명만 맞춰 안내한다.

## 작업 흐름

사용자가 어느 단계부터 요청하든 해당 단계부터 시작한다. 대본이 첨부되면 1단계를 건너뛰되,
**대본을 8초 블록 4개로 재배치하는 작업(1-B)은 항상 한다.**

### 1단계. 30초 대본 쓰기

입력: 주제(예: "70대 아파트 경비원이 입주민에게 갑질당하다 반전"), 시대(현대/조선), 원하면 반전 아이디어.

구성 원칙:
1. **0~3초 훅**: 첫 대사나 첫 동작 하나로 갈등이 바로 보이게 한다 (던지기, 소리치기, 무릎 꿇리기 등).
2. **갈등 고조**: 가해자의 요구가 단계적으로 세진다. 주인공은 말없이 참는다. 목격자 한 명이 있으면 좋다.
3. **반전**: 주인공의 숨겨진 신분·권한·증거가 드러난다. 반전의 근거는 미리 한 번 암시해 둔다(봉투, 반지, 명패 등).
4. **마무리 펀치라인**: 주인공이 목소리를 높이지 않고 짧게 한마디. 가해자의 표정 붕괴로 끝낸다.

야담(조선 배경)이면 같은 구조를 쓰되 신분 반전(암행어사 마패, 대감의 정체, 몰락 양반의 문서 등)으로 바꾸고,
복식은 `yadam-flow-prompts` 스킬이 있으면 그 고증 기준을 따른다.

출력 형식 (`references/prompt-templates.md`의 "1단계 출력 형식"):
- 대본 제목
- 스토리 한 줄 요약 (대본 맨 위)
- 시간 구간별 화면 / 인물 대사 / 연출
- 제작 메모 (반전 핵심 컷, 음향 포인트)

### 1-B. 8초 블록 재배치 (Veo 3 전용, 필수)

대본을 `0~8 / 8~16 / 16~24 / 24~32초` 4개 클립으로 다시 나눈다.

- 각 클립은 **하나의 장소, 한두 개의 카메라 움직임, 대사 1~2줄**만 담는다.
- 대사 분량: 한국어는 자연스러운 속도로 초당 약 5~6음절. 8초 중 동작·리액션 2초를 빼고 **클립당 합계 35음절 이내**.
  넘치면 대사를 줄이고, 줄인 내용을 사용자에게 표로 보여 준다(원문 → 수정본).
- 클립 경계에서는 인물 위치·자세가 이어지게 한다. 클립 N의 마지막 순간 = 클립 N+1의 시작 순간.
- 반전 서류처럼 **글자가 중요한 컷은 별도 인서트**로 빼서 2단계에서 정지 이미지로 만든다.
- 최종 30초는 편집에서 컷 사이 여유분을 잘라 맞춘다고 메모한다.

### 2단계. 시작 키프레임 + 레퍼런스 이미지 프롬프트

Flow의 이미지 생성(나노바나나) 또는 Gemini 앱에 넣을 프롬프트를 만든다. 영어 본문 + 필요 시 한국어 설명.

반드시 만드는 것:
1. **키프레임 1장 (클립 1의 시작 프레임)**
   - 대본의 첫 장면, 훅 직전의 순간 (동작이 시작되기 바로 전).
   - 주인공 얼굴이 정면에 가깝게 보이고 의상이 식별되는 구도.
   - 감정이 표정·자세에 드러남.
   - 9:16 세로, 실사 한국 드라마 톤, **글자·자막·워터마크 없음**.
2. **인물 레퍼런스 시트** (주인공 + 주요 상대역 각각 1장): 단색 배경, 정면 상반신, 같은 의상.
   클립 2~4에서 Ingredients 이미지로 넣어 얼굴·의상 흔들림을 줄인다.
3. **반전 인서트 이미지** (필요할 때만): 서류·마패·명패 클로즈업. 글자는 최소화하고,
   정확한 이름·문구는 편집 자막으로 넣으라고 안내한다.

결과 정리:
- 장면 설명 (인물, 표정, 배경, 구도)
- 이 구도를 고른 이유 한 줄
- 이미지별 프롬프트 원문 (복사용 코드 블록)

### 3단계. Veo 3 클립별 영상 프롬프트

클립 4개 각각에 대해 Flow에 넣을 프롬프트를 만든다. 템플릿은 `references/prompt-templates.md`.

규칙:
1. 프롬프트는 **영어로 장면·카메라·소리를 쓰고, 대사만 한국어 원문**으로 큰따옴표 안에 넣는다.
   화자는 생김새로 지정한다 (`the elderly security guard in the navy uniform says in Korean: "..."`).
2. 클립 안의 시간 구간을 적는다: `[0-3s] ... [3-8s] ...`
3. 장면마다 동작, 표정 변화, 카메라 움직임(고정·느린 줌인·팬·핸드헬드)을 정한다.
4. 키프레임에 없는 인물·장소는 생김새, 의상, 배경을 구체적으로 묘사한다.
5. 매 클립마다 같은 인물 묘사 문구(캐릭터 앵커)를 **글자 그대로 반복**한다.
6. 소리: `No background music. Only dialogue and natural ambient sound: ...` 를 매 클립에 넣는다.
7. 매 클립 끝에 `No subtitles, no captions, no on-screen text, no watermark.` 를 넣는다.
8. 각 클립에 **Flow 설정 메모**를 붙인다: 모드(Frames to Video / Ingredients to Video / Extend),
   시작 프레임으로 쓸 이미지, 넣을 레퍼런스, 비율 9:16, 생성 개수.

결과 정리:
- 클립별 시간 구간 (원본 대본 구간과의 대응)
- 클립별 연출 표: 동작 / 표정 / 카메라 / 대사
- 클립별 Veo 3 프롬프트 원문 (복사용 코드 블록)
- Flow 조립 순서와 편집 체크리스트 (`references/flow-veo3-guide.md`의 "편집 마무리")

## 3분 미드폼 모드 (Veo 인트로 + 브루·캡컷 본편)

사용자가 "3분", "미드폼", "롱폼과 쇼츠 사이", "인트로만 영상으로" 같은 요청을 하면 이 모드로 만든다.
목적은 30초 쇼츠와 롱폼 사이를 잇고 구독으로 연결하는 것이다. 자세한 형식은 `references/midform-hybrid.md`.

1. **대본 (2분 30초~2분 59초).** 이야기에서 가장 강한 장면을 맨 앞에 콜드 오픈으로 둔다.
   30~40초마다 "그런데…"로 시작하는 재후킹 문장을 넣는다. 결말은 완결하고, 마지막 5초에 다음 편을 예고한다.
2. **인트로 = Veo 3 클립 2개 (16초).** 위 3단계 규칙(키프레임, 캐릭터 앵커, 대사 음절 제한, 배경음악·자막 없음)을 그대로 따른다.
3. **본편 = 브루 나레이션 + 장면 이미지 + 캡컷 효과.** 장면표에 파일명(`s03.png`~), 이미지 내용, 나레이션, 효과를 적는다.
   나레이션은 한국어 TTS 기준 분당 약 320음절로 계산하고, 전체가 2분 59초를 넘지 않게 음절 수를 세어 알려 준다.
4. **장면 이미지 프롬프트.** 인물 레퍼런스(R1~)를 먼저 만들고, 장면마다 첨부할 레퍼런스를 표시한다.
   공통 스타일 문구, 줌·팬을 위한 여백, 영상과 같은 캐릭터 앵커를 쓴다.
5. **편집 메모.** 배경음악(1분 넘는 쇼츠의 저작권 음원 차단 주의), 효과음, 관련 동영상 링크, 고정 댓글, 30초 예고편 재활용 방법.

## 생성 전 확인 (원본의 "임의로 바꾸지 말 것" 원칙 유지)

다음 중 하나라도 해당하면 프롬프트를 끝까지 쓰기 전에 사용자에게 먼저 알리고 선택지를 준다.
- 대사가 클립당 35음절을 넘어 줄여야 할 때 → 원문/수정안 표 제시
- 사용자가 "한 번에 30초"를 원할 때 → Veo 3는 8초 단위라 4클립 + 이어붙이기가 필요하다고 설명
- 반전에 꼭 필요한 글자(이름, 금액)가 화면에 정확히 나와야 할 때 → 인서트 이미지 또는 편집 자막 권장
