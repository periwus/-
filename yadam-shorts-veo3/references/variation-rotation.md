# 회전표: 매 영상 다르게 만들기

목적은 두 가지다.
1. **유튜브 "진정성 없는 콘텐츠"(대량 생산·반복 콘텐츠) 판정을 피한다.** 채널 영상이 같은 틀에 이름만 바뀐 것처럼 보이지 않게 한다.
2. **다른 채널의 창작 표현을 베끼지 않는다.** 구조는 장르 문법이라 써도 되지만, 구체적 장치·대사·결말 소품은 매번 새로 만든다.

---

## 1. 뼈대 4종 (뼈대도 돌린다)

| 코드 | 뼈대 | 흐름 | 어울리는 이야기 |
|---|---|---|---|
| **K1** | 콜드 오픈 되감기형 | 가장 이상한 장면 → "하루 전," → 쌓기 → 반전 → 여운 | 정체·과거 인연 반전 |
| **K2** | 시간순 누적형 | 평범한 시작 → 이상한 일이 3번 반복되며 커짐 → 3번째에 진상 | 오싹, 욕심의 대가 |
| **K3** | 액자형 | 늙은 화자가 "내가 어릴 적 본 일인데…"로 시작 → 옛이야기 → 마지막에 화자의 정체 | 감동, 후일담 반전 |
| **K4** | 두 시점 교차형 | 주인공 시점과 상대 시점을 번갈아 보여 줌 → 두 이야기가 한 장면에서 만남 | 오해 풀기, 누명 |

30초 쇼츠는 K1·K2만 쓴다. 3분 미드폼은 4종 모두 쓸 수 있다.

## 2. 부품 8종

| 코드 | 부품 | 선택지 |
|---|---|---|
| **T** | 이야기 유형 | T1 은혜 갚기 · T2 희생과 보답 · T3 정체 숨긴 고수 · T4 억울한 누명 풀기 · T5 지혜 대결 · T6 욕심의 대가 |
| **O** | 콜드 오픈 | O1 인물의 질문 · O2 충격적인 행동 · O3 결말 장면 먼저 · O4 나레이터의 경고 문장 · O5 소리만 들림(검은 화면 + 소리) |
| **V** | 시선 | V1 나레이터 3인칭 · V2 주인공 1인칭 회고 · V3 목격자(아이, 주모, 하인) 시선 · V4 낯선 존재의 시선 |
| **N** | 반전 수 | N1 한 번 크게 · N2 두 번 · N3 세 번 연속 |
| **R** | 반전 종류 (마지막 반전 기준) | R1 정체 · R2 과거 인연 · R3 숨겨진 의도 · R4 시간(사실 몇 년 전 일) · R5 물건의 비밀 |
| **E** | 결말 장치 | E1 소품이 바뀜 · E2 마지막 대사 한 줄 · E3 계절이 바뀐 장면 · E4 후일담 나레이션 · E5 다음 편 예고 |
| **M** | 감정 톤 | M1 감동 · M2 통쾌 · M3 오싹 · M4 해학 |
| **C** | 중간 문구 | C1 두 번 두드리기 · C2 질문 던지기("여러분이라면?") · C3 없음 |

**조합 코드 예:** `K1-T2-O1-V1-N3-R2-E1-M1-C1`

## 3. 고르는 규칙

1. **작업 시작 전에 최근 제작 기록을 묻는다.** "최근 영상들의 조합 코드가 있으면 붙여 주세요."
   기록이 없으면 그대로 진행하고, 결과 끝에 기록 줄을 주며 저장하라고 안내한다.
2. **직전 영상과 감정 톤(M)과 이야기 유형(T)이 달라야 한다.**
3. **최근 5편 중 어느 영상과도 9개 칸 중 5개 이상 같으면 안 된다.**
4. **같은 뼈대(K)는 3편 연속 쓰지 않는다.**
5. **감정 톤 비율은 최근 10편 기준으로 한 톤이 절반을 넘지 않게** 한다. 넘으면 사용자에게 알린다.
6. 사용자가 특정 부품을 지정하면 그 칸은 따르고, 나머지 칸만 규칙에 맞춰 고른다.
7. 시리즈물(같은 주인공)은 주인공은 고정하되, 회차마다 T·R·E를 반드시 바꾼다.

## 4. 원작 보호 규칙 (레퍼런스 영상을 받았을 때)

- 레퍼런스 영상에서는 **뼈대 코드와 부품 코드까지만** 뽑는다. 예: "이 영상은 K1-T2-…에 가깝다".
- 그 영상의 **구체적 장치는 쓰지 않는다.** 핵심 소품, 결정적 대사, 반전의 구체적 방법, 결말 이미지가 해당한다.
  예: 레퍼런스가 "관이 밥상으로 바뀜"이면 E1(소품이 바뀜)은 써도 되지만 관·밥상은 쓰지 않는다.
- 레퍼런스와 **같은 존재 + 같은 반전 종류** 조합은 피한다. 예: 저승사자 + 과거 인연.
- 대본을 쓸 때는 레퍼런스 대사를 다시 보지 않고, 원전 민담이나 새 설정에서 출발한다.
- 사용자에게 레퍼런스와 무엇이 다른지 한 줄로 알려 준다.

## 5. 출력에 붙이는 것

대본 맨 위, 한 줄 요약 바로 아래에 붙인다.

```
회전표: K1-T2-O1-V1-N3-R2-E1-M1-C1
고른 이유: 직전 영상이 M2(통쾌)·T4(누명)여서 감동·희생으로 바꿈. 최근 5편과 겹치는 칸 최대 3개.
```

대본 맨 끝에는 아래를 붙인다.

```
📌 제작 기록 (메모장에 저장해 두고 다음 요청 때 붙여 주세요)
YYYY-MM-DD | <제목> | K1-T2-O1-V1-N3-R2-E1-M1-C1
```

## 6. 사람 손길 체크 (진정성)

매 영상에서 아래 중 **2개 이상**이 들어가게 대본에 표시한다.
- [ ] 채널 고정 도입 문구 (예: "오늘 밤 들려드릴 이야기는…")
- [ ] 이야기 끝 채널만의 한 줄 해설·교훈
- [ ] 원전과 다르게 바꾼 지점 한 가지 (설명란에 "원전에서는 ○○이지만 이 이야기에서는…")
- [ ] 직접 녹음한 목소리 또는 직접 고른 고정 나레이터
- [ ] 시리즈 회차·세계관 연결 (전 편 인물의 짧은 등장)

설명란에 넣을 문구도 함께 준다:
